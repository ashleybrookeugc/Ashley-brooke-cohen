Accessibility

Last updated September 9, 2026.

Our intent

Ashley Brooke Cohen intends this site to be usable by as many visitors as possible and continues to improve it as the site grows.

Current measures

  • Semantic headings, landmarks, buttons, and navigation links.
  • Keyboard-operable filters and event-detail controls with visible focus indicators.
  • Text labels for subway lines, rather than color alone.
  • Readable contrast, meaningful link labels, and responsive layouts.

Feedback

A public accessibility-contact destination has not yet been published. Once a contact method is supplied, this page and the Contact page will be updated so visitors can report an accessibility problem directly to Ashley.

Event details can change. Verify with the official source before traveling.
