## Cross-clip calibration findings

### Metrics that appear comparatively stable under the cached evidence

1. **Identity clarity** — evaluators can usually distinguish clips that clearly reveal Ashley's professional/personality lane from clips that mainly show scenery or an external object.
2. **Audience relevance** — role-specific relevance is visibly different across acting, brand, entertainment, and first-time-viewer perspectives.
3. **Communication effectiveness** — problem/solution, thesis, review, and reflection structures are distinguishable even in the cached summaries, although final scoring still needs complete timeline evidence.
4. **Portfolio contribution** — redundancy/new-coverage distinctions are already visible across the two Tribeca clips and the two Sedona clips.
5. **Commercial usefulness** — the stress test supports a clear rule that a brand appearing in-frame is not enough; experience/product communication must actually be demonstrated.

### Metrics/anchors that remain high-risk or ambiguous

1. **Capability proof** — highest ambiguity. The rubric must force evaluators to name the exact demonstrated capability rather than awarding broad creator/actor competence. Examples: actor looks ≠ acting range; brand sighting ≠ brand communication; montage construction ≠ proof of every production craft.
2. **Credibility** — needs strong anchor discipline so firsthand specificity counts, while production polish, brand familiarity, or confident delivery do not automatically become credibility.
3. **Distinctiveness** — must distinguish "specific point of view" from "rare topic." A common topic can still be distinctively framed; an unusual location/object is not automatically Ashley-distinctive.
4. **Execution quality** — cannot be meaningfully calibrated from the current compressed cache because pacing, audio, framing, text readability, and technical defects require timeline-level evidence.
5. **Entertainment/casting usefulness** — needs a strict distinction between on-camera personality/presentation and actual dramatic/comedic performance evidence.

## N/O stress-test findings

The current rules appear workable if applied narrowly:

- `N/O—FORMAT` is appropriate when the clip genuinely does not attempt the task, e.g. scenic montage for acting/performance evidence or a non-commercial acting clip for product communication.
- Use numeric weakness rather than N/O when the relevant task is attempted but poorly demonstrated.
- `N/O—CORPUS` is only for portfolio contribution when the comparison set is unavailable. In this provisional pass the comparison set exists for the 10 cached clips, so corpus contribution can be discussed diagnostically.

No authorship-based N/O is used.

## Provisional disagreement map

Because this run does not contain multiple independent raters per perspective, valid inter-rater percentages cannot be computed. However, the board-role stress test predicts the greatest future disagreement in these pairings:

- capability proof: broad competence vs exact demonstrated skill;
- entertainment/casting usefulness: personality/presence vs performance evidence;
- commercial usefulness: organic experience review vs actual brand/product task;
- credibility: firsthand specificity vs unsupported authority signaling;
- distinctiveness: unusual subject vs distinctive Ashley framing;
- execution quality: polish vs whether craft actually improves comprehension/evidence.

These should receive special attention during the true blind calibration.
